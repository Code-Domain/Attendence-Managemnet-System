About the Project

Student Attendance Reporting System is a modern web application designed to simplify attendance management for schools and colleges.

It allows administrators and teachers to manage student records, record attendance, view reports and monitor attendance statistics through dedicated administrator and teacher workspaces connected to a shared database.

  • Fast & Responsive
  • Shared Organization Database
  • Role-Based Access
  • Beautiful Glassmorphism UI
